# task 4:  Dashboard Design

## Project Overview
This project is about creating an interactive sales dashboard using Power BI.

The dashboard helps business stakeholders analyze sales performance using KPIs, charts, and interactive visuals.

## Tool Used
- Power BI

## Dataset
Dataset used: Superstore Sales Dataset

The dataset contains sales-related information such as:
- Order Date
- Sales
- Category
- Region
- Segment
- Customer Details
- Product Details

## Dashboard Features

### KPI Cards
Created summary cards for:
- Total Sales
- Total Orders
- Total Customers

### Visualizations
Created interactive charts:
- Sales Trend Over Time
- Sales by Category
- Sales by Region
- Sales by Segment

## Interactivity
The dashboard includes:
- Interactive charts
- Cross-filtering between visuals
- Hover tooltips for details

## Files Included
- Power BI Dashboard (.pbix)
- Dashboard Screenshots
- PPT Summary
- README.md

## Outcome
Created an interactive business dashboard to understand sales trends and support data-driven decisions.
